\privateproject{Distributed Observability Pipeline (Datadog-style)}{datadog}
\stack{Go, Rust, Apache Kafka, ClickHouse, Prometheus, Grafana, Kubernetes, Terraform}
\begin{points}
  \item Built an end-to-end metrics pipeline: a Go ingestor (Gin HTTP, with gRPC/protobuf definitions) publishing validated metrics to 6-partition Kafka topics with a dead-letter queue, consumed by a Rust/tokio processor running EWMA and rolling Z-score anomaly detection.
  \item Ensured at-least-once delivery with no silent data loss by committing Kafka offsets only after successful ClickHouse writes, and protected the consumer loop with a circuit breaker (opens after 5 failures, exponential backoff to 60s) so backend degradation bounds lag instead of stalling ingestion. Storage is two-tier: Prometheus (15-day hot) and ClickHouse MergeTree (monthly partitions, 1-year TTL, hourly rollups).
  \item Built the operational layer: per-tenant token-bucket rate limiting, W3C Trace Context propagation to Tempo and Jaeger, multi-window SLO burn-rate alerts on the Google SRE model, a 12-component Helm chart with HPAs and PDBs, and a Terraform blueprint for AWS EKS. Backed by 53 unit tests (41 Go, 12 Rust), 25 integration tests, and a k6 load-test script for the 14-container stack.
\end{points}
